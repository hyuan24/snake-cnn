# snake-cnn

tensorflow_model.ipynb contains a convolutional neural network for classifying snake images by species. Achieves ~98% accuracy on six species. 
WebScraper.ipynb contains a Selenium-based web scraper that downloads full-size JPEGs to a local directory.
